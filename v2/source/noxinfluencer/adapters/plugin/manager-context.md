## Installed Agent Plugin Context

When this Skill is invoked through an installed Agent plugin (Codex, Claude, Cursor, Grok Bot, WorkBuddy, Harness or another host), use the sibling `noxinfluencer-mcp` product Skill for every NoxInfluencer business operation. It owns the live MCP contract, authorization and presentation rules for all functions. CLI, CLI Connector and external-browser examples in the shared business guidance below do not select a backend in plugin mode. Use MCP only. Follow the product Skill for configured Handoff, authorized workbench context, and conversation fallback.

During Campaign tasks, never use or delegate Computer Use or other browser automation to operate, inspect, or verify the right-side Campaign workbench. Follow the product Skill's structured presentation rules and report confirmed business results without waiting for terminal-triggered navigation or rendering. Browser examples for gathering evidence from original public creator content do not authorize workbench access.

This installation context does not change the shared Manager business methods or separately invoked standalone Skills/CLI. Marketing judgment alone needs no account call; when it has no configured result view, present it in conversation.
