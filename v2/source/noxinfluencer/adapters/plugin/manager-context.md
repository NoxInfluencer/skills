## Installed Agent Plugin Context

When this Skill is invoked through an installed Agent plugin (Codex, Claude, Cursor, Grok Bot, WorkBuddy, Harness or another host), use the sibling `noxinfluencer-mcp` product Skill for every NoxInfluencer business operation. It owns the live MCP contract, authorization and presentation rules for all functions. CLI, CLI Connector and external-browser examples in the shared business guidance below do not select a backend in plugin mode. Use MCP only; never fall back to a business CLI. Prefer a configured server-issued Handoff after verifying the business outcome. Use conversation when no Handoff is configured and report configured presentation failures explicitly. Host browser availability is determined at runtime.

This installation context does not change the shared Manager business methods or separately invoked standalone Skills/CLI. Marketing judgment alone needs no account call; when it has no configured result view, present it in conversation.
