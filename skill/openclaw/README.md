# OpenClaw Skill Notes

本目录保存 OpenClaw Skill 的本地规范参考。

开发或维护 OpenClaw Skill 前，先阅读：

1. `skill/openclaw/OPENCLAW_SKILL_SPEC.md`
2. OpenClaw 官方文档中的 Skills / Creating Skills / CLI skills
3. 本项目的 `CLAUDE.md`、`AGENTS.md`、`docs/项目介绍.md` 和相关业务模块文档

本目录的目标不是替代 OpenClaw 官方文档，而是把当前项目开发 OpenClaw Skill 时必须遵守的规范和来源整理到一起，减少遗漏。

当前目录包含：

- `OPENCLAW_SKILL_SPEC.md`：OpenClaw Skill 规范整理
- `discover-creators/SKILL.md`
- `analyze-creator/SKILL.md`
- `nox-account/SKILL.md`
- `outreach-creators/SKILL.md`
- `track-performance/SKILL.md`
