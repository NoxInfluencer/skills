# MCP File Results

Use the catalogued template, export, export-status and report-preparation tools with their live schemas. Preserve returned file and export identities. A template result does not establish file-import support, and a completed export does not establish that a local file was downloaded.

Use only service-returned result links or a file-transfer capability actually supplied by the current Host. Do not construct routes, pass local paths or file bytes into business tools, attach OAuth credentials to a result URL, or fabricate upload IDs. Before replacing an existing local file, obtain approval for that destination and overwrite.

If no usable result link or Host transfer exists, report the completed business task and the remaining file-delivery limitation. Missing file transfer does not block unrelated reads or writes.
